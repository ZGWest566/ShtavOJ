# Shtav OJ

> 一个没有服务器、没有数据库、没有沙箱、没有后端的在线评测系统。
>
> 它确实能跑。至于为什么能跑，不要问。

---

## 这是什么

一个部署在 GitHub Pages 上的纯前端 OJ。所有逻辑跑在用户浏览器里，数据存在第三方 JSON 剪贴板，评测交给 Codeforces，结果靠公共 CORS 代理轮询。

你的 API 永远不会被限流，因为你根本没有 API。

## 架构

```
GitHub Pages (你唯一的"服务器")
      │
      ├── fetch → JSONBlob (数据库)
      │
      └── fetch → CORS 代理 → Codeforces API (评测机)
```

三层全部借来的，一层都不属于你。

## 工作流程

1. 用户在页面上写代码
2. 点击"提交"，代码被写进共享 JSON blob
3. 用户跳转到 Codeforces，手动粘贴、提交
4. 前端通过 CORS 代理轮询 Codeforces API
5. 匹配到提交后，把 verdict 写回 JSON blob
6. 其他人刷新页面，看到更新的排名

评测的可靠性，取决于用户的耐心。

## 特性

- ✅ 零后端，零运维，零成本
- ✅ 部署只需要一个 GitHub 仓库
- ✅ 数据公开透明，所有人共享同一个 blob
- ✅ 并发写入会互相覆盖，这是特性不是 bug
- ✅ CORS 代理随时可能挂，挂了就挂了

## 快速开始

1. 开启 GitHub Pages
2. 打开页面，创建你的账号
3. 开始赤石

## 已知问题

- 数据可能丢失
- 提交可能被覆盖
- 代理可能失效
- 评测可能匹配错提交
- 排名可能不准
- 用户可能被封号
- 项目可能随时停止维护

以上均为预期行为。

## 为什么叫赤石

因为你在用一堆不属于你的服务，搭一个不该存在的东西。

它没有事务，没有一致性，没有可靠性，没有安全性。它有的只是一个静态页面和一堆 `fetch`。

但它确实能跑。
